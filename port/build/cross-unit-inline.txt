# port/build/cross-unit-inline.txt: game functions defined `inline` (or `__forceinline`, which the PC build spells
# `inline`) in one unit's .cpp and called from other units. The Xbox build links them with LTCG; on the PC the defining
# unit emits a COMDAT copy the others link to (CMakeLists.txt, halo3_defines). That holds at -O0, where every call stays
# a call; with optimization the defining unit inlines all its own calls and drops the copy, and the other units'
# references would fall to link-stage1's stubs. Each name here (its MS-mangled, IR spelling) is kept out of line in its
# defining unit (LLVM ForceFunctionAttrs: -mllvm -force-attribute=<name>:noinline), so the copy is emitted at any
# optimization level; a name a unit does not define changes nothing there. The proper fix is a game change (define
# these in headers, or not inline): GAME-CHANGES F80.
#
